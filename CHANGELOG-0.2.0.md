# BETA-0.2.0

- Добавлен сбор карт колодой: Shift + ПКМ по установленной колоде собирает карты из рамок вокруг неё обратно в колоду
- Радиус сбора настраивается в config.yml (deck-collect-cards-radius, по умолчанию 8)
- Сбор ограничен вместимостью колоды (максимум 56 карт), лишние карты остаются на месте
- Исправлено взятие карты из рамки: карта выдаётся игроку, рамка убирается
- Исправлен выброс карты из меню колоды (Q или клик мимо окна): содержимое колоды обновляется, проигрывается звук
- Исправлена анимация взятия карты (не исчезала, улетала сквозь землю)
- Исправлена анимация сбора карт (была не видна)
- Минимальная версия повышена до 1.21
- Релокация Kotlin в ru.hukm.pokercards.libs.kotlin
